# Glossário

| Termo | Significado |
|---|---|
| print | Mostra algo na tela |
| input | Recebe dados do usuário |
| variável | Guarda informações |
| int | Número inteiro |
| str | Texto |
| try | Tenta executar um código |
| except | Trata erros |

# Exemplos de Código

## Código simples

```python
print("Olá mundo")

nome = input("Digite seu nome: ")

print(nome)

try:
    numero = int(input("Digite um número: "))

    print(numero)

except ValueError:
    print("Digite apenas números")
```
